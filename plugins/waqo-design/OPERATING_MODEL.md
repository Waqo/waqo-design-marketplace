# waqo-design Operating Model

The skills are intentionally separated.

- `frontend-design` creates and implements visual direction.
- `design-critique` evaluates product and visual quality.
- `design-system` formalizes reusable rules.
- `ux-writing` owns interface language.
- `accessibility-review` performs formal accessibility inspection.
- `research-synthesis` converts user evidence into design implications.
- `design-handoff` turns settled decisions into engineering specifications.

Do not make `frontend-design` duplicate every specialist workflow.

When multiple skills are relevant, sequence them according to the work:
research → concept → prototype → critique → accessibility → system → handoff.

For existing products:
inspect → critique → targeted specialist work → implement → verify.
