# Screenshot Critique and Anti-Default Tests

Use after rough implementation and again before final polish.

Prefer:
Concept → rough implementation → screenshot → critique → recompose → screenshot → polish.

Do not polish a weak composition.

## Five-second test

At a glance:
- what appears first;
- whether that is correct;
- whether the primary job is obvious;
- whether there is a recognizable visual thesis;
- whether there is one memorable move.

## Thumbnail test

Reduce the design mentally or literally.

Does the silhouette remain distinctive, or does it collapse into header + sidebar + card grid?

## Blur test

Squint or blur.

Are the visual masses and hierarchy still intentional?

## Grayscale test

If color disappears, does hierarchy survive?

## Swap test

Replace:
- logo;
- product name;
- copy.

Could the UI now belong to HR, finance, CRM, AI, or project management with no structural changes?

If yes, the product-specific concept is underdeveloped.

## Card-count test

Count visible elevated or bordered rectangles.

For each, ask whether containment is doing semantic work.

## Decoration audit

Remove one decorative device.

If the design does not become worse or less clear, keep it removed.

## Structural response

If critique reveals generic composition, do not fix it only with:
- radius;
- shadow;
- accent color;
- minor spacing;
- tiny type adjustments.

Recompose:
- dominant region;
- axis;
- density;
- navigation;
- container strategy;
- primary object;
- signature interaction.

## Anti-default radar

Patterns that often become generated-design defaults include:
- uniform rounded-card matrices;
- arbitrary bento grids;
- giant gradient headlines;
- gratuitous glass;
- dark UI + one neon accent;
- cream + editorial serif + warm clay accent;
- purple/blue AI glow;
- pills everywhere;
- same radius at every level;
- repeated soft shadows;
- fake terminal chrome;
- decorative monospace;
- tracked all-caps eyebrows;
- arrow appended to every CTA;
- mesh blobs and floating spheres;
- icon/title/paragraph feature grids.

None are forbidden.

Do not spend free creative choice on them without a product reason.
